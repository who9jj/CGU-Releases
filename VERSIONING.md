# Public release policy

The original version is tagged `cgu-v1.0.0`; keep that tag and its assets intact. Future production versions use semantic version tags such as `v1.0.1` or `v1.1.0`, selected explicitly by the owner. Do not reuse an existing version for different bytes.

New installers include a versioned filename, release notes, upgrade guidance and SHA-256 checksums. Publication follows complete Windows installer and recovery qualification. Private UAT builds are not public production releases. Repository/documentation maintenance does not announce or publish a new installer.
