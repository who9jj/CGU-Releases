# GDE V1 Known Limitations

These are deliberate V1 scope boundaries, not broken V1 workflows.

- **Native Dynasty Year Remapping** is deferred to V2. GDE can present supported calendar labels without claiming to rewrite NCAA's native dynasty-year semantics.
- **GDE Start Screen integration** is an optional presentation project and is not part of core V1.
- **NCAA 13 compatibility** is future work; this release targets NCAA 14 / College Football Revamped.
- **Madden support** is outside NCAA 14 V1.
- **Raw native Coach XP semantics** remain intentionally unmapped. GDE normalizes the supported presentation rather than inventing an unsafe native interpretation.
- **Unproven native fields** remain untouched. GDE does not expose an edit merely because a field exists in a save.

GDE also does not turn read-only planning tools into automatic NCAA changes. Position Change Lab, Program Momentum, analytics/history, Offseason Decision Center analysis, and What-If scenarios remain planning surfaces unless a separate supported workflow explicitly owns an approved write.
